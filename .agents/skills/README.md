# Skills

Skills are reusable workflow knowledge.

Use skills for repeated domain behavior that is too long for `AGENTS.md`.

## Starter Skills

- `project-orientation`
- `internal-contracts`
- `implementation`
- `quality-audit`

## Skill Rules

- Keep skills scoped.
- Reference authoritative project files.
- Do not duplicate large playbooks when a link is enough.
- If a local instruction conflicts with a skill, the local instruction wins.
