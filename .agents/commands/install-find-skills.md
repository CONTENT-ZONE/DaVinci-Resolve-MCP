# Install Find Skills

Run this command to initialize skills in your project:

```bash
npx skills init
```

Run this command to install the `find-skills` skill. This meta-skill will teach your AI agent how to search for, discover, and install other useful skills from the open ecosystem:

```bash
npx skills add https://github.com/vercel-labs/skills --skill find-skills --agent universal
```

## Update Skills

To update your installed skills to their latest versions from the repository, simply run:

```bash
npx skills update
```
